    Altium API

    Use altium_api.v1 to load a design and follow its electrical connections. For reporting rule violations, see Checks. Model classes can be imported from the same namespace or accessed through models:

    from altium_api.v1 import DesignData, models

assert DesignData is models.DesignData

    Project data loading

    load_project_data(context, input_parameters) returns a DesignData snapshot. Read components and nets from project.schematic_model, and project metadata, schematics and variants from the root. Pass variantName or variantGuid in the input dictionary to filter the schematic model; the variant catalog stays complete. Use get_project_parameters for project-level name/value pairs.

    The model fields below are frozen. Collections are tuples; a required field whose type includes None can still have a null value. Use model_dump() or model_dump_json() to serialize a model.

    For connectivity, see Graph navigation. On a loaded project, graph_for(project).net_for(pin) returns a net object or None; pin.net is just its name. Missing or ambiguous IDs do not establish a connection.

    Graph navigation

    Call graph_for(project) on a loaded design to traverse connections. pins_for(component) returns its pins; nets_for(component) returns the distinct connected nets. net_for(pin) and component_for(pin) return None when a connection or owner cannot be resolved. variant_for(component) returns the variant name, if present.

    graph_for(model: BaseModel) -> DesignGraph

    nets_for 

    nets_for(component: DesignDataComponent) -> tuple[Net, ...]

    component_for 

    component_for(pin: DesignDataPin) -> Component | None

    net_for 

    net_for(pin: DesignDataPin) -> Net | None
